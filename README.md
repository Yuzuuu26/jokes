# Jokes
## Jokes is a program focused on reading jokes off of files while also allowing the user to add/write jokes into the file.

## How to use:
### Adding or writing jokes into the csv file.
1. In the terminal, navigate to the folder dist.
2. Then, write node write-csv.js on the terminal.
3. Input the necessary information such as the jokes, its punchline, etc.
4. Exit the program by entering 0 into the terminal.

### Reading jokes from the csv file
1. In the terminal, navigate to the folder dist.
2. Then, write node read-csv.js on the terminal.
3. An instruction and a range of numbers will be displayed. Pick one and it will display the joke corresponding to that number.
4. You can continue searching for jokes or you can exit the program by entering 0 into the terminal.
